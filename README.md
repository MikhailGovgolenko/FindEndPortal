<h1 align="center">FindEndPortal</h1>

<p align="center">Web version: https://findendportal.govgolenko.ru/</p>

A utility to calculate trajectories and locate Minecraft Strongholds using Eyes of Ender.

Available as a web application and a portable Windows desktop application.

<img width="1536" height="863" alt="image" src="https://github.com/user-attachments/assets/41fbc128-a1d0-40d0-8723-106fb3745246" />

### How to use:

1. **Open** FindEndPortal.
2. Throw an **Eye of Ender** and enter your current X/Z coordinates and throw angle.
3. Move to a new location (preferably 100–200 blocks away, perpendicular to the first throw direction).
4. Throw another **Eye of Ender** and enter the new coordinates and angle.
5. View the calculated Stronghold coordinates, which update automatically as you enter data.

---

The Windows version is fully standalone, requires no installation, and leaves no traces on your system.
